# Computer Use MCP 驱动的 Windows 端到端验收手册（#83）

> 本文档供具备视觉能力的 AI（或人工）在真实 Windows 桌面通过 Computer Use MCP
> （鼠标/键盘）执行 #73 全部导入/核对/保存/导出流程的**操作手册**。
> 强制约定：**验收不通过 DOM、测试选择器或直接 IPC 绕过界面**；必须使用真实文件选择/
> 保存对话框、系统 OCR、PDF 阅读器、Microsoft Word 和 WPS；保留截图、耗时与复测报告。

## 0. 前置条件与准备

| 项 | 要求 | 备注 |
| --- | --- | --- |
| Windows 桌面会话 | 有可交互桌面（非 headless）；关闭会拦截点击的悬浮层（NVIDIA Overlay、PiDeck、Clash 等） | 悬浮层会拦截真实鼠标点击 |
| 中文 OCR 语言包 | 设置 → 时间和语言 → 语言 → 中文(简体) → 语言选项 → OCR | 缺失时按「OCR 错误」场景验收（#37/#81） |
| Microsoft Word / WPS | 两者之一或都装（DOCX 可编辑性验证） | 本机已验证 Word 可用 |
| 验收样本 | `npm run dev` 前准备 `{任意目录}/zhangwei.docx`、`zhangwei-text.pdf`、`scan.pdf`（无文本层）、混合/乱码/双栏 PDF | 合成材料，勿用私人简历 |
| 模型配置 | 设置页配置一个可用模型（验收 Agent 增强路径）；不配置则验收 Agent 降级路径 | 首次导入会弹隐私同意 |
| 独立 Pi（Kimi） | 仅 #80 对比需要；缺失时按 blocker 记录 | 不得用项目认证 |

启动：`npm run dev`（渲染进程 localhost:5173；窗口出现后确认置于前台）。

## 1. DOCX 导入闭环

1. 点左侧导航「简历」→ 点「上传解析」→ 真实文件对话框选择 `zhangwei.docx`（路径可直接键入文件名框后回车）。
2. 观察导入弹窗阶段：读取文件 → 解析文本 → 生成草稿 →（Agent 结构化或降级原因）。
3. 首次使用 Agent：弹隐私告知 → 选择「同意并继续」；再次导入不再询问。
4. 导入完成 → 打开完整编辑器 + 「导入核对」面板：
   - 提取全文、字段来源（姓名/电话/邮箱/教育）、待确认项、未映射内容可见；
   - 姓名「张伟」、电话「138-0000-1234」、教育「北京理工大学」来自文本提取。
5. 删除姓名 → 点「确认并创建基准简历」→ 保存被 schema 校验阻止并定位「基本信息/姓名」。
6. 补齐姓名 → 确认 → 列表新增 1 份基准简历（原列表条数不变，未覆盖/未合并）。
7. 验证溯源：不显示原文/路径/诊断（仅标题与更新时间）。

截图：① 导入弹窗进度 ② 核对面板 ③ 校验阻止 ④ 确认后列表。

## 2. 文本型 PDF 导入

1. 「上传解析」选 `zhangwei-text.pdf` → 完成进入编辑器。
2. 核对面板「提取全文」含 `===== 第 1 页 =====` 标记；字段来自文本提取。
3. 确认后新建基准简历；溯源 fileType=pdf、parsePath=text。

## 3. 扫描型 PDF（OCR）与 OCR 错误

1. 选 `scan.pdf`（无文本层）→ 弹窗显示「OCR 识别 第 N/M 页」进度，可点「取消」。
2. 取消 → 离开前弹确认 → 确认后不创建任何简历（列表无新增）。
3. 重新导入 `scan.pdf` → OCR 完成进入编辑器（字段来自 OCR）；
   缺失语言包时显示「OCR 引擎不可用——请确认系统已安装中文语言包」+
   「重试 / 换文件 / 手动新建」入口，三条路径均可点。
4. 记录：三页扫描简历从选文件到草稿就绪的总耗时（目标 ≤10s；实测记录）。

截图：① OCR 进度 + 取消 ② 语言包缺失错误 + 替代入口。

## 4. 混合/乱码/双栏 PDF（逐页路由）

1. 混合 PDF（第 1 页文本、第 2 页扫描）→ 核对面板「逐页解析」：
   第 1 页 文本提取、第 2 页 OCR；parsePath=mixed（确认后溯源可见）。
2. 双栏 PDF → 面板显示「双栏已按坐标重排」，阅读顺序正确。
3. 乱码/替换字符页 → 自动走 OCR；OCR 结果仍乱码 → 「低置信度（请重点核对）」标记。

## 5. Agent 降级路径

1. 未配置模型或设置中关闭「Agent 导入增强」→ 导入完成后核对面板显示
   「Agent 未使用：<原因>（已用本地草稿，可人工补齐）」，草稿可用。
2. Agent 等待超 30s → 弹「继续等待 / 使用本地草稿 / 取消导入」；选「使用本地草稿」立即出草稿。

## 6. 导出 PDF / DOCX（基准与优化简历）

1. 基准简历行点「导出」→ 菜单选「导出 PDF」→ 真实保存对话框（过滤器 PDF）→ 保存；
   **取消** → 提示「已取消导出」且不生成文件；打开生成的 PDF 确认可读。
2. 选「导出 DOCX」→ 保存对话框（过滤器 .docx）→ 保存。
3. 优化简历（职位详情内先生成一份优化稿）→ 同样双格式导出。
4. 编辑器内修改未保存 → A4 预览弹窗点「导出 DOCX」→ 先校验并保存 → 再弹保存框；
   校验失败则阻止导出并定位问题。

## 7. Word / WPS 兼容与内容核对

1. 用 Microsoft Word 打开导出的 DOCX：文字/段落/列表可编辑（点选、增删文字）；
   照片存在；章节顺序与 A4 预览一致；空章节不出现；多行描述为圆点列表；长内容自然分页。
2. 用 WPS 打开同一 DOCX 重复上一步（允许细微分页差异）。
3. PDF 用阅读器（如 SumatraPDF）打开正常。
