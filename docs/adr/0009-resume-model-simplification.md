# 简历模型简化：技能三段式与项目精简

基准简历的录入体验决定模型形态：技能改为固定三分类（工程能力/科研能力/其他能力）各一段话描述（删除 items 列表与熟练度）；项目经历精简为 名称/起止时间/一段话描述/技术栈（删除 角色/要点/链接）。basics 新增可选照片（复制到应用数据目录，A4 头部右侧显示；优化稿生成时继承基准照片）。

原因：结构化字段（逐条要点、技能词条、熟练度）的录入与维护成本超过了它们在规则匹配中的边际收益，用户明确选择简洁。匹配度/优化稿 prompt/面试复盘随模型适配（技能匹配维度改为段落文本覆盖，项目维度仍依赖 description+techStack）；旧数据以一次性迁移脚本转换。关联工单：wayfinder map「简历模块可用」。
